Most companies don't have a data problem. They have a reporting problem: the same numbers get rebuilt by hand every week, and by Friday nobody trusts them.

I build the systems that stop that — scheduled dashboards, automated payroll, order tracking that updates itself.

Currently **MIS Executive at MG Acryplast Industries**, where I:

- Replaced a fully manual sales-reporting cycle with an automated Looker Studio pipeline — **8+ hours a week** back, zero rebuilds
- Built **7 salesperson dashboards** covering pending orders, payment plans, meetings and stock
- Run the CRM and Order-to-Delivery trackers behind **~100 orders/month**
- Cut shop-floor reporting time **20%** with a Google Forms → Sheets capture system that now feeds every operational dashboard

Enterprises for a **70+ person** manufacturing unit: **15% faster reporting**, **100% payroll accuracy**, **98% budget adherence**, and a KPI framework across production, supply chain and quality that supported an **8% revenue increase**.
